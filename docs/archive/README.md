# Session archive

Chronological records of the working sessions that produced this branch, kept so
the reasoning survives even when the chat that produced it is gone.

| File | Session | Dates |
|---|---|---|
| [SESSION-01-rebuild.md](SESSION-01-rebuild.md) | Rebuilt the app from a 103-line calculator; 18 commits | 23 Aug – 19 Sep 2026 |

## What belongs here, and what does not

These are **narrative records**: what was asked, what was done in response, what
was found, and what was decided at each step. They are append-only history. Once
a session file is written it is not edited except to fix an outright error.

The living documents are elsewhere and are the ones to trust for current state:

| For | Read |
|---|---|
| Where the work stands now | [../HANDOFF.md](../HANDOFF.md) |
| What to do next | [../TODO.md](../TODO.md) |
| Why the code is shaped this way | [../DECISIONS.md](../DECISIONS.md) |
| A commit-by-commit summary | [../DEVELOPMENT_LOG.md](../DEVELOPMENT_LOG.md) |

If an archive file and a living document disagree, **the living document is
right** — the archive records what was true at the time.

## Adding a session

Number it in sequence, name it for what the session was about, and add a row to
the table above. Record the reasoning, especially anything rejected and why;
that is the part which is expensive to reconstruct and impossible to infer from
the diff.
